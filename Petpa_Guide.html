🐾 Petpa 寵物系統操作指南

這是一份為買家、合作商家（貓舍）以及平台管理員（後臺）準備的快速上手教學。

目前系統已經在 http://localhost:3000 運行中！

🛍️

一、買家（消費者）如何使用？

買家可以透過專屬的貓舍推廣連結進入賣場，進行商品瀏覽與結帳。

  1. 進入賣場： 開啟連結 http://localhost:3000/shop/cattery-a (可以將 cattery-a 換成對應貓舍的代號)。
  2. 瀏覽商品與活體： 在賣場內，您可以切換標籤來瀏覽不同分類的商品（例如幼貓展示牆、貓砂、清潔用品等）。
  3. 加入購物車： 點擊商品卡片上的「+ 加入購物車」，然後可以增減數量。
  4. 前往結帳： 畫面底部會浮現購物車總計，點擊「前往結帳 →」按鈕。
  5. 完成下單： 進入結帳頁面後，您可以點擊「🔑 買家登入」進行一鍵快速登入，接著選擇付款方式並點擊「確認付款下單」。

二、商家（貓舍/合作夥伴）如何使用？

商家可以管理自己的專屬賣場，並查看透過自己推廣連結產生的訂單（分潤或業績）。

  1. 進入商家後台： 開啟連結 http://localhost:3000/seller/dashboard。
  2. 查看儀表板： 在這裡您可以看到本月的業績、點擊量、以及轉換率等數據。
  3. 管理商品上架： 商家可以決定要不要將平台方提供的商品上架到自己的專屬賣場，並可以自訂「推薦標籤」及「自訂價格」。
  4. 幼貓活體上架： 您可以在後台管理目前正在尋找新家的貓咪，上傳血統證書或合約 PDF。
  5. 查看訂單： 在「我的分潤訂單」中追蹤已成立的買家訂單。
前往商家後台

三、總管理員（平台後臺）如何使用？

總管理員擁有最高權限，負責全站的商品資料庫維護、商家管理以及訂單出貨。

  1. 進入總管理後台： 開啟連結 http://localhost:3000/admin/dashboard。
  2. 商品資料庫 (PIM)： 您可以統一新增、編輯、下架所有商品。這些商品可供各合作貓舍挑選上架到他們的專屬頁面。
  3. 管理合作貓舍： 在「合作貓舍管理」頁面，您可以新增新的合作夥伴，配置分潤 % 數，並設定他們的提領帳戶。
  4. 訂單處理與出貨： 所有成立的訂單都會匯集至「全站訂單總覽」，管理員可在此核對買家匯款，並更改訂單狀態為「已出貨」。
  5. 全站財務與報表： 追蹤平台的總營收、待撥款給商家的分潤金額。
前往總管理後台

其他注意事項

  • 開發環境： 系統目前正運行於您的本機背景，如果您重新開機，記得輸入 npm run dev 重新啟動。
  • 資料庫連線： 系統使用 MongoDB 作為資料庫（預設連線為 mongodb://mongo:27017/PETPA）。若有部署需求可串接 Mongo Atlas。
